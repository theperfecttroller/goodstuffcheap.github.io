quicklinks and stuff i made, live at https://goodstuffcheap.github.io

### adding a quicklink
open `index.html`, find `const LINKS` near the bottom and copy one line\
`url` opens a page, `copy` copies text when clicked (like a discord name)\
`icon` is one of the keys in `ICONS` right below it, leave it out for a plain arrow
